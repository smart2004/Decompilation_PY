## Decompilation_PY

Разложение исполняемого файла (.exe), созданного из Python-кода, на исходный код и вспомогательные файлы можно выполнить с помощью ряда инструментов и шагов. Вот подробное руководство:

1. Определение типа файла
Убедитесь, что файл действительно является исполняемым файлом, созданным из Python (например, с помощью PyInstaller, cx_Freeze или py2exe).

2. Использование инструментов для декомпиляции
Для извлечения исходного кода из .exe файла, созданного с помощью PyInstaller, вы можете использовать следующие инструменты:
PyInstaller Extractor: Это скрипт на Python, который позволяет извлекать файлы из .exe, созданного с помощью PyInstaller.
git clone https://github.com/extremecoders-re/pyinstaller-extractor.git
cd pyinstaller-extractor
python pyinstxtractor.py your_file.exe
pyinstxtractor.py: Этот скрипт извлечет все файлы, включая .pyc файлы (скомпилированные файлы Python).

3. Декодирование .pyc файлов
Если после извлечения вы получили .pyc файлы, вам нужно декомпилировать их обратно в .py файлы. Для этого можно использовать:
uncompyle6: Этот инструмент позволяет декомпилировать .pyc файлы обратно в читаемый Python код.
pip install uncompyle6
uncompyle6 -o . your_file.pyc

4. Извлечение ресурсов
Если в .exe файле есть дополнительные ресурсы (например, изображения, конфигурационные файлы), они также могут быть извлечены с помощью PyInstaller Extractor. После извлечения вы сможете найти их в той же директории.

5. Анализ полученного кода
После декомпиляции и извлечения кода изучите его, чтобы понять логику программы. Обратите внимание на возможные зависимости и используемые библиотеки.

6. Отладка
Если необходимо, используйте отладчик, такой как pdb в Python, чтобы пошагово выполнять код и анализировать его поведение.

7. Документация
Записывайте свои находки, добавляйте комментарии к коду и создавайте документацию, чтобы облегчить дальнейшее понимание.

8. Законодательные аспекты
Обратите внимание на юридические аспекты реверс-инжиниринга. В некоторых случаях это может быть незаконно без разрешения владельца программного обеспечения.

Заключение
Реверс-инжиниринг Python .exe файлов требует терпения и понимания Python. Эти методы рекомендуется использовать только для образовательных целей или с разрешения владельца программного обеспечения.
